# 轻量桌面重构执行清单

更新：2026-09-05。本文是后续工作的唯一进度清单；其他历史计划不作为完成依据。

目标：减少安装体积和日常写盘，收敛重复实现，保留文档编辑、AI 写作、资料引用和导出。已移除 Playwright，已完成的局部缓存限额不重复计为本轮成果。

执行规则：按下面顺序实施；每次改动补相应验证，验证后才勾选。不得整体删除 `.data`、密钥或用户文档。保留已有未提交修改。失败不隐式切换模型、不扩大编辑范围。未跑 GUI/真实模型/打包的项目不得标记验收通过。

## P0：入口与可控启动

- [x] A1 统一产品入口为桌面；浏览器服务仅保留显式开发入口。默认 CLI、双击入口和快速开始一致；缺少桌面依赖时清楚报错，不自动退回浏览器。已通过入口契约测试，真实窗口验收见 D2。
- [x] A2 启动入口不检查模型、不启动 Ollama、不下载模型。已移除两处启动预热代码并通过禁止隐式下载的回归；未配置 API 时真实窗口能否完整使用仍由 D2 验收，任务内部迁移见 C6。
- [x] A3 修正桌面无限 reload、阻塞等待及服务退出生命周期。服务启动等待限 30 秒、非阻塞定时检查、失败不自动刷新、退出请求停止并最多等待 5 秒；已通过替身契约测试，真实 GUI 见 D1/D2。
- [ ] A4 修正桌面下载接口，禁用无用插件；不默认关闭浏览器沙箱。验收：桌面 API 契约测试及实际导出验证。
- [ ] A5 完成桌面容器最终取舍。当前复用 PySide + Svelte，不新增第二套桌面实现；测量 QtWebEngine 体积后决定是否迁移系统 WebView，不能将测试浏览器删除等同于去除内嵌内核。
