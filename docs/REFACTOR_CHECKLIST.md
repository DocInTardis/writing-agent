# 轻量桌面重构执行清单

更新：2026-09-19。本文是后续工作的唯一进度清单；其他历史计划不作为完成依据。

目标：做一款面向 AI 初稿后深度编辑的“块感知专业分页编辑器”。它组合 Word 的连续编辑、样式与分页，Notion 的块选择与组织，Markdown 的高效输入，以及 AI 的结构化生成与精确修改。继续保持轻量桌面、受控写盘和单一实现，不以堆功能或复制多套编辑路径换取表面完整度。

执行规则：按下面顺序实施；每次改动补相应验证，验证后才勾选。不得整体删除 `.data`、密钥或用户文档。保留已有未提交修改。失败不隐式切换模型、不扩大编辑范围。未跑 GUI/真实模型/打包的项目不得标记验收通过。

## 产品定义与不可退让的编辑原则

- 文档在视觉和键盘操作上是一条连续编辑流；页面和块边界不能把正文拆成互不相通的输入框。
- 用户能够感知块：段落、标题、列表、图片、表格、公式等都有轻量边界、稳定 ID 和块级操作；未悬停或未选中时不持续制造视觉噪声。
- 普通回车拆分块，段内自动换行不拆块，`Shift+Enter` 插入软换行；段首退格和段尾 Delete 自然合并相邻文本块。
- 文字选择、块选择和文档/章节操作是三个明确层级。文字工具栏不冒充块工具栏，块菜单不干扰跨段选择。
- 用户与 AI 必须调用同一套 Document V3 命令；AI 不能直接覆盖 HTML、绕过撤销历史或产生另一种不可编辑结果。
- 分页是 Rust 布局结果在同一编辑文档上的视图映射，不为每一页创建独立编辑器，也不在前端估算或写死页码。
- Markdown 是输入快捷方式和可交换文本格式，不作为丢失样式、对象、引用及页面信息后的唯一文档真相。
- 优先保证编辑可靠性，再增加功能数量。输入法、撤销、粘贴、跨块选择、保存恢复未通过前，不推进装饰性功能。

- [ ] D1.1 建立编辑行为矩阵：中文/英文输入法、组合输入、回车、软换行、退格合并、Delete 合并、上下左右键跨块、Home/End、跨段选择、全选、复制、剪切、粘贴、拖选和双击/三击选择。
