# 轻量运行与空间边界

## 日常只用一条路径

双击 `start.bat` 或运行 `scripts/start_desktop.ps1` 打开桌面窗口。首次创建 `.venv` 并安装桌面依赖；后续复用。当前仍使用 PySide + 内嵌 Svelte 界面，并不是无浏览器内核的原生编辑器。
依赖文件变更或环境需要修复时运行 `scripts/start_desktop.ps1 -InstallDependencies`。安装过程不保留 pip 下载缓存。
`scripts/start.ps1` / `python -m writing_agent.launch --web` 仅用于显式开发调试。普通 CLI `python -m writing_agent.launch` 默认打开桌面。
启动不探测模型、不启动 Ollama、不下载模型；用户可以先打开界面再配置 API。任务执行中的旧模型路径仍在收敛中，不能视为已全部迁移。

默认只保留一个 `.venv`。运行环境和开发环境不是两份产品：需要开发时，把 `requirements-dev.txt` 安装到同一个环境即可。

## 按需启用，不作为日常前置条件

- Svelte / Node：修改前端时才需要，日常使用已构建的静态文件。
- Node AI 网关：只在选择该接入方式时运行。
- Rust 引擎：只在修改或验证原生引擎时编译。
- PySide 桌面壳：当前桌面入口依赖；首次使用桌面启动脚本安装 PySide6。
- Tauri：实验入口，暂不作为默认运行方式。
- 浏览器自动测试链路已移除，不再安装 Playwright 或下载专用测试浏览器。

## 哪些空间可以清理

只读盘点：`.\.venv\Scripts\python -B -m writing_agent.storage_report`。
输出分类大小、顶层目录和读取错误，不读取文件内容，不跟随链接，不执行删除。分类不等于删除许可；`.data` 始终按受保护数据处理。

| 类别 | 位置 | 规则 |
|---|---|---|
| 用户文档、资料、工作区 | `.data/` | 不得整体当作缓存删除 |
| 默认运行依赖 | `.venv/` | 日常保留 |
| Rust 编译产物 | `engine/target/`、`desktop-tauri/src-tauri/target/` | 无编译任务时可删除，下次编译重建 |
| 前端开发依赖 | 各组件 `node_modules/` | 开发时保留；删除后需联网重新安装 |
| 额外测试环境和旧环境备份 | 历史 `.venv-*`、`.venv313` | 确认不被使用后清理，不作为常驻目录 |
| 共享下载缓存、测试浏览器 | C 盘用户缓存目录 | 可能被其他项目使用，不随本项目自动删除 |

生成文本缓存默认限制为 500 条、7 天、正文合计 64 MiB，在打开缓存和写入时清理过期内容及超限条目。过大的单条结果不缓存，更新已有条目不额外占用条数。索引采用紧凑 JSON 和原子替换，同进程缓存实例共享状态。该限制只覆盖索引登记的缓存正文，不包括索引文件、未登记文件、其他缓存或用户资料；不是全局磁盘配额，也不提供跨进程同步。

## 本轮不做什么

保留用户资料、各组件源码和原有功能，不重建 Rust，不新增测试浏览器，也不同时重写编辑器、数据库和模型接入层。
后续架构工作优先取消服务对 `app_v2` 的反向依赖，并为前端加入独立类型检查。

生成工作流的依赖边界及迁移进度见 `AGENT_ARCHITECTURE.md`。

## 日常写盘策略

- 两个启动脚本禁用 Python 字节码写入，并传给子进程；不会删除已有 `__pycache__`。
- 阶段耗时默认不落盘。仅当 `WRITING_AGENT_PERSIST_PHASE_METRICS=1` 时按任务结束/关闭批量保存，最多保留 200 条诊断记录；不会每个阶段重写文件。
- 常规生成直接使用流式事件中的完整内容，默认不创建中间文本块文件；表格和图形在未落盘时同样直接传内容，不发出无对应文件的 ID。旧文件仍能按 ID 读取。
- 仅当 `WRITING_AGENT_PERSIST_TEXT_BLOCKS=1` 时启用旧的文件块路径。新的无指定 ID 文本块按内容去重；相同内容再次生成不再创建随机编号副本。内容寻址的新 ID 不原地修改，避免影响共享引用。
- 文本块及检查点采用原子替换；JSON 紧凑保存，检查点内容未变化时不重复写入。检查点遵守 `WRITING_AGENT_DATA_DIR`。
- 本轮不自动删除旧文本块或检查点：块仍被 API 按 ID 读取，跨文档引用与任务完成落盘的回收边界尚未统一。诊断开关不控制其他模块的日志/指标，不等同于全应用零写盘。
